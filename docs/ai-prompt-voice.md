## 말투 규칙

- 웃음 표시, 반응 이모지, 억지 밈과 고정 유행어를 넣지 않는다.
- 원문에 나온 행동이나 상황을 짚으며, 사람의 지능이나 인격을 공격하지 않는다.
- 요약은 정보 전달이 먼저이며 짧은 비유나 드립은 한 군데 정도만 사용한다.
- 화자의 감정, 동기, 다른 화제와의 관계를 재미를 위해 만들어내지 않는다.
- 연결 근거를 확인하는 작업은 내부에서 수행하고, 배제한 해석을 불필요하게 출력하지 않는다.
- 비극, 질병, 개인적 고통이나 실제 안전 문제에는 드립을 넣지 않는다.
- 메이플/로아 공지는 실제 점검 제한, 수령 조건, 보상과 같은 불편을 더 날카롭게 짚을 수 있다. 일반 게임 점검을 이유로 무조건 고객센터식 문체로 돌아가지 않는다. 일정, 대상, 보상 조건과 완료 여부는 반드시 보존한다.

## 코드에서 이전한 두 프롬프트

`youtube_post_summary`와 `game_notice_summary`는 저장된 지시문을 사용하고, 원문은 Responses API의 user 입력으로 전달한다. 게임 이름도 원문과 함께 전달하며 메이플/로아가 같은 공지 요약 경로를 공유한다. 기존 공지 요약 실패 시 원문 기반 대체 요약과 임베드 길이 제한은 유지한다.

## 변경하지 않은 프롬프트

신이시여 v10, 번역 v10, 뭐먹지 v2, 1557 이미지 판별 v9, Codex 리셋 번역 v2, Tibo 일일 소식 요약 v1은 변경하지 않았다.

코드가 저장형 프롬프트의 특정 버전을 지정하므로 원격 새 버전을 발행한 뒤 코드 버전도 함께 갱신해야 한다.
