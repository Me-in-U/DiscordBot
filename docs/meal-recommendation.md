# 국내 배달 식사 추천 범위

2026-10-26에 공개된 공식 자료를 조회해 `/뭐먹지`의 범위를 조정했다. 앱 화면 전체나 특정 주소의 실시간 가게 목록을 수집한 결과는 아니다.

## 조사와 적용 기준

- [쿠팡이츠 음식 카테고리 등록 기준](https://partners.coupangeats.com/start-guide/step-1/2870/)은 치킨, 피자, 버거, 한식, 중식, 일식, 아시안 등 음식 종류별 분류와 실제 메뉴 예시를 제공한다. 쌀국수, 포케 등도 국내 배달 분류에 포함되므로 외국에서 유래했다는 이유만으로 제외하지 않았다.
- [배민의 카테고리별 주문 안내](https://ceo.baemin.com/guide/12416)는 분식, 치킨, 버거, 중식, 도시락, 백반/죽/국수, 찜/탕/찌개, 고기/구이 등을 구분한다. 이 자료의 설문과 주문 통계는 2023~2024년 자료이므로 현재 인기 순위나 추천 가중치로 사용하지 않았다.
- 요기요 웹사이트는 조회 시 403 응답으로 본문을 확인하지 못했다. 세 앱의 최신 카테고리가 완전히 같다고 가정하지 않았다.

국가별 순환을 없애고 식사 중심의 17개 분류로 재구성했다. 한식, 찜/탕/찌개, 국밥/국수, 분식, 치킨, 피자, 버거, 중식, 돈까스, 일식, 회/해물, 족발/보쌈, 고기/구이, 양식, 아시안, 도시락/죽, 샐러드/샌드위치다. 공식 분류를 그대로 복제한 목록이 아니라 겹치는 분류를 묶고 식사 목적에 맞춰 나눈 서비스용 분류다.

각 분류에는 익숙한 메뉴 6개씩, 총 102개를 두었다. 음료, 디저트, 식재료, 장보기 상품, 특정 가게나 브랜드는 제외했다. 실제 목록은 `cogs/meal_recommendation/__init__.py`의 `MEAL_RECOMMENDATION_CATEGORIES`에서 관리한다.

## 추천 동작

- 분류를 섞어 한 바퀴씩 순환하고 해당 분류의 허용 메뉴 목록을 저장 프롬프트에 전달한다.
- 기존 프롬프트 변수 이름 `cuisine`은 호환성을 위해 유지하되, 값에는 국내 배달 분류와 허용 메뉴를 넣는다.
- 모델이 전체 허용 목록 밖의 메뉴를 반환하면 거부한다. 빈 응답이나 최근 20개 추천과 겹치는 응답도 한 번 재시도하며, 다시 실패하면 오류를 안내한다.
- GPT 6 Luna의 추론 없음과 낮은 출력 상세도를 유지한다. 최근 추천 기록은 프로세스 메모리에 저장하므로 재시작 시 초기화된다.

주소나 영업 중인 가게를 조회하지 않으므로 특정 지역에서 지금 주문할 수 있음을 보장하지 않는다. 메뉴 목록은 국내 배달에서 흔히 접하는 식사를 고르기 위한 제한이며, 특정 앱의 전체 메뉴나 인기 순위가 아니다.

회귀 테스트는 저장 프롬프트 호출, 분류 순환, 최근 추천 제외, 목록 밖 응답 거부와 재시도 및 오류 처리를 다룬다. 이번 변경에서는 테스트를 작성했으며 실행하지 않았다.
